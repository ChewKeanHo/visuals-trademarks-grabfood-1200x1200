# This is the official list of trademark owners for trademark verification
# purposes. This file is distinct from the `CREATORS.txt`, `CONTRIBUTORS.txt`,
# and `LICENSE.txt` files. For example, the company holding the registered
# trademark ownership regardless of project copyright is listed here.
#
# List should be sorted as follows:
#   1. [YEARS] in decending order; AND THEN
#   2. Alphabetical order within the same [YEARS]
#
# Each entry **MUST COMPLY** with the following pattern:
#     |Trademark [YEARS] [LOCATION]:[TRADEMARK_ID] [ENTITY_FULL_NAME] (OPTIONAL_URL) <OPTIONAL_EMAIL>|
# Legends:
#   * [YEARS]
#       - Trademark works on effective registered range (e.g. successful annual
#         registration renewal).
#       - The last year of ownership indicates the registration is expired and
#         post expiry processes begins.
#       - To reduce manual tracking ending year manually for project maintenance
#         sake, use star (`*`) to indicate manual verification is required
#         (e.g. '2026-*').
#   * [LOCATION]
#       - The registered trademark effective locations (e.g. 'State, Country').
#       - Trademark is territorial. For more locations, please create new entry
#         for each.
#   * [TRADEMARK_ID]
#       - The registered trademark ID associated to the granted year and
#         location.
#       - Trademark is territorial in nature. For more registrations, create new
#         entries for each of them.
#   * [ENTITY_FULL_NAME]
#       - The legal entity's goverment registered full name.
#   * [OPTIONAL_URL]
#       - The entity's provided URL to contact with.
#       - It is enclosed with rounded parenthesis (**`( )`**) as defined by
#         programming syntax for automation and parsing purposes.
#       - When doing a re-distribution, between the upstream source URL and the
#         bio-page, choose the upstream source for maintaining the upstream
#         source location relationship in addition to actual ownership.
#       - This is optional if URL is unavailable. However, Trademark requires at
#         least 1 contactable channel so ensure the alternatives are available.
#   * [OPTIONAL_EMAIL]
#       - The entity's provided email to contact with.
#       - The address is enclosed with angled parenthesis (**`< >`**) as defined
#         programming syntax for automation and parsing purposes.
#       - This is optional if the email is unavailable. However, Trademark
#         requires at least 1 contactable channel so ensure the alternatives are
#         available.
